# CN Blender Tech Hub Assets

本仓库为 **BLENDER 超级技术交流社** 公共资产库，用于收藏群内成员开源共享的插件及扩展资产。

欢迎各位收藏与使用，也期待您的贡献。

## 仓库内容

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| edge_extrude | 1.9.15 | 挤出边 — 实时控制挤出宽度与高度的网格边挤出工具 |
| hide_pie | 1.8.5 | 隐藏饼菜单 — 集合所有隐藏功能的快捷饼菜单 |
| one_click_hole | 1.0.11 | 一键布线开洞 — 编辑模式下一键布线开洞 |
| rainbow_noodle_line | 1.0.6 | 彩虹节点曲线 — 为节点编辑器连接显示彩虹曲线与边框 |

## 使用方式

1. 通过本仓库的 `raw` 直链下载 zip
2. 在 Blender 中 `偏好设置 → 插件 → 安装` 选择 zip 即可
3. 或通过 [RARA Extensions](https://raracannot.github.io/extensions/) 分发仓库在线安装

## 贡献指南

- 欢迎群内成员提交自己开发或收集的开源插件资产
- 请确保上传的资产遵循开源许可（如 GPL-3.0），尊重原作者版权
